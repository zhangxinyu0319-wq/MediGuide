# Plan Better action rules

The page prioritises up to three short actions per category generated from the selected plan record, plan tier, documented deductible/co-insurance, named benefit limits, health conditions, mapped medicine names, stated cost/coverage preference and user-entered usage log.

Rules include:
- Hospital: tell the user which ward tier the selected plan is described for; surface deductible/co-insurance and known panel/non-panel annual-limit differences (Raffles Shield Private and HSBC Life Shield Plan A).
- Surgery: distinguish MediShield Life's fixed surgical table from as-charged IP surgery; suggest day-surgery comparison only where the treating clinician considers it suitable.
- Specialist: state the plan's documented pre/post-admission windows and named panel/non-panel time differences; do not treat unrelated routine visits as covered.
- Emergency: distinguish admission-linked ED care from standalone A&E and ambulance limits; never delay emergency treatment.
- Medication: map entered medicines to likely indications, but never infer reimbursement. Advise users to budget for routine medicines when the supplied summary does not list them and to discuss generics only with a clinician/pharmacist.
- Outpatient: surface only source-described dialysis, psychiatry, cancer-drug and CDMP pathways when user conditions match. CHAS clinic directory is linked only as a public primary-care route, not as an insurer panel.
- Usage history: report only user-entered events and out-of-pocket totals; do not infer claim acceptance or that a benefit was unused because no entry exists.
- User preference: cost-first messaging foregrounds ward tier, patient-share amounts and eligible public funding routes; coverage-first messaging foregrounds the plan's named higher-limit and condition-linked benefits.

The supplied PDFs do not include current named insurer hospital/specialist panel directories, the user's location, live clinic capacity, drug retail price lists or complete prescription formularies. Therefore the app does not name a hospital as insurer-approved, invent a medicine purchase budget, or recommend buying extra medication. Specific provider selection requires current insurer network records and location.

The PDFs are policy summaries, not complete contracts. Benefits can depend on exact diagnosis, treatment, policy version, age, rider, provider, deductible, co-insurance, sublimits, exclusions and claim adjudication.
