# MediGuide fixes — 29 October 2026

## Deployment
This ZIP contains the complete `MediGuide-GitHub-Ready/` repository folder. Extract it and upload that folder at repository root (not the ZIP itself). Keep Cloudflare Pages root directory `MediGuide-GitHub-Ready`, build output `.`. GitHub commit triggers the existing production deployment.

## Fixed
- Onboarding relies on `state.completed`, not whether the first age question was filled. Answers advance one screen at a time and the summary appears after final save.
- Homepage displays age-based estimated monthly premium from the user-provided Data.pdf schedule unless a monthly amount was actually entered by the user, in which case the displayed label identifies it as user-reported.
- Different coverage-fit weight distributions for four priority types (affordability, balanced, unexpected bills, complete coverage); displayed on suitability methodology page.
- Compare cards show `Recommended fit` / `Suitable fit` when questionnaire is complete, data permits a meaningful fit rating, and the rule-based score reaches the threshold. This is not a purchase or underwriting recommendation. Affordability-first rankings require age-bracket premium information; otherwise no label.
- Gemini backend: API errors for model not found and malformed request now return a more informative error message, without exposing the Gemini key. 503 status can still mean a Google API/model issue; look at the actual chatbot error. Gemini model availability and free quotas cannot be guaranteed.

## Limitations
- Insurance plan figures are sourced from the user's PDF; not independently verified with insurers.
- Customer-specific policy exclusions, actual premiums, rider discounts and health-related underwriting decisions cannot be inferred from profile answers.
- Client-side saved profiles are per browser/device. Secure server-side medical profiles are not implemented.
- Gemini requires an enabled and accessible model in your actual Google AI Studio account, sufficient quota, and valid Cloudflare secrets. The chatbot cannot be live-tested here.
